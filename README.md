
# Sobre o projeto Gerenciamento-de-Contratados

Projeto com uma proposta de ser uma pagina capaz de gerenciar documentos e seus respectivos status, consulta, e acompanhamento
de pendencias, tendo como objetivo melhor organização para areas administrativas.

# 🎨 Desing

Ultilizando a ferramenta de desing Figma, essa etapa do projeto me deu umpouco de dificuldade para decorar onde cada ferramenta do
Figma fica mas achei bastante interessante e pratico.
